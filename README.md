# Dynamic Brightness Mod

A Fabric mod for Minecraft 26.3 that provides seamless brightness transitions between different environments.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API for Minecraft 26.3
- Cloth Config 26.3.0 or newer

Mod Menu 21.0.0-beta.1 or newer is recommended for in-game configuration.
