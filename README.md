# Dynamic Brightness Mod

A Fabric mod for Minecraft 26.2 that provides seamless brightness transitions between different environments.

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.3 or newer
- Fabric API for Minecraft 26.2
- Cloth Config 26.2.0 or newer

Mod Menu 20.0.1 or newer is recommended for in-game configuration.
